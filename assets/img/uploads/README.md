# Upload the real photography here

Drop the five source images into this folder using **exactly** these filenames
(any image format is fine — `.jpg`/`.png`/`.webp` — just keep the base name):

| Filename (any extension) | Slot | Replaces |
| --- | --- | --- |
| `hero.*` | Full-bleed header | `assets/img/placeholder-hero.svg` |
| `sprinter.*` | Lookbook 01 | `assets/img/placeholder-sprinter.svg` |
| `boxer.*` | Lookbook 02 | `assets/img/placeholder-boxer.svg` |
| `highjump.*` | Lookbook 03 | `assets/img/placeholder-highjump.svg` |
| `kick.*` | Lookbook 04 | `assets/img/placeholder-kick.svg` |

## How to upload on GitHub

1. Open this folder in the repo: `assets/img/uploads/`
2. Click **Add file → Upload files**
3. Drag in the five images (named as above), commit directly to `main`
4. Once they're in, the site will be updated to reference them here instead of
   the SVG placeholders, and this folder's contents get moved into
   `assets/img/` proper.

No need to resize or convert anything first — that'll get handled during the swap-in.
